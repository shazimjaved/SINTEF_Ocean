1.3 Engineering reference versus observed clean condition
The towing-tank report supplies a clean-bottom engineering assumption. It does not prove a dated clean condition in
the observed sensor series. The audit found no verified cleaning chronology or clean-labelled sensor interval. The
sea-trial image is a candidate reference whose provenance still needs confirmation. No first month, post-gap period or
template timestamp is assigned a clean label here. [V2, V3, A1]
